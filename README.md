# Healthcare Management System

A React-based healthcare management application for patient and admin management.

## Features
- Patient dashboard and profile management
- Appointment booking system
- Report generation and management
- Admin panel for managing patients and appointments

## Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. Copy `.env.example` to `.env` and configure your API URL
4. Start development server: `npm run dev`

## Build
```bash
npm run build
```

## Technologies Used
- React 19
- Vite
- Tailwind CSS
- Axios
- Chart.js
- React Router DOM

## Scripts
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
